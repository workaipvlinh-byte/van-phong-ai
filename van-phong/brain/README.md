# Bộ não chung (Second Brain)

Nhân viên nào cũng đọc thư mục này trước khi làm việc.

- `00-ve-chu.md`: công ty làm gì, khách là ai, giọng văn, điều cấm. Sửa ngay trên bảng điều khiển (bấm bộ não ở giữa).
- `99-ghi-nho.md`: nhắn `/nho <điều cần nhớ>` trong Telegram là được ghi vào đây.
- Muốn thêm file nào cứ tạo thêm file `.md` trong thư mục này.
