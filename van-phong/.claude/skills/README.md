# Skill cho nhân viên

Mỗi skill là 1 thư mục, bên trong có file SKILL.md: tên, khi nào dùng, các bước làm.
Bỏ thư mục skill vào đây là nhân viên nào cũng dùng được. Skill mẫu: viet-bai-ban-hang.
Skill tải từ nơi khác thì đọc kỹ trước khi bỏ vào: skill là lời dặn cho AI, ai viết gì AI làm theo nấy.
